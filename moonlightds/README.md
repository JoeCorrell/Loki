# Moonlight DS

Moonlight DS streams two independent Windows displays to the AYN Thor.

## Quick start

1. Install a virtual display driver on the PC, then run **Sunshine DS** and complete its web setup.
2. Install **Moonlight DS.apk** on the Thor.
3. Add the PC, pair it with the new PIN, and enable **Second screen** in Moonlight DS settings.
4. Start the Desktop stream. The primary monitor uses the top screen and the virtual monitor uses the bottom screen.

## Controls

- Press **Start** to open settings.
- Two-finger tap the bottom screen to show or hide the on-screen keyboard.
- Touch either stream to control the mouse on that monitor.
- Press **Back** to leave the stream and close Moonlight DS on both screens.

If a game needs the Start button, turn off **Session → Start opens these settings**.
